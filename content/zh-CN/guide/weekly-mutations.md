## 页面结构

侧栏「每周突变」有两个标签页：

- **本周突变**：当前一周的突变安排。
- **突变因子**：完整的因子资料库。

右侧「刷新」按当前标签页重新拉取数据。切到「本周突变」时还会显示服务器切换：**国服 CN / 美服 NA / 欧服 EU / 亚服 AS**，默认国服。

## 本周突变

卡片展示本周内容：

| 字段 | 说明 |
| --- | --- |
| 突变名称 | 标题行 |
| 数据状态 | 「已核验」或「轮换推算」 |
| 任务地图 | 本周使用的对战地图 |
| 时间 | 北京时间下的生效区间 |
| 最近核验 | 服务端确认该安排的最近时间 |
| 本周突变因子 | 本周启用的因子列表 |
| 社区评分 | 该突变的社区打分 |

**两种数据状态的差别**：「已核验」表示本周安排已由服务端核验资料确认；「轮换推算」是按历史轮换顺序推算出来的结果，通常在官方尚未放出新一周资料时出现，因此存在偏差可能。

资料到期时卡片会提示「本周资料已过期」，刷新即可取回最新安排；当前时间落在服务端安排的有效期之外时，会说明「当前时间不在服务端安排的有效期内」。某个服务器暂时没有资料时显示「暂无本周安排」。

## 突变因子

这一页是全部因子的资料库，可按名称或描述搜索，标题旁显示「共 N 个因子」。每个因子显示图标、名称与说明，用于提前判断本周突变难在哪。搜索无结果时提示「没有匹配的突变因子」。

## 在线校准与本地数据

每周突变的默认数据来自应用内的本地资料与规则，不依赖登录。只有在同时满足以下两个条件时，才会向官方服务请求校准结果：

1. 「设置 → 功能管理 → 星际枢纽官方服务」已开启；
2. 「每周突变在线校准」子开关已开启。

关闭校准不影响查看突变，只是全部结果都会按本地推算显示，卡片上的状态也就不会是「已核验」。
