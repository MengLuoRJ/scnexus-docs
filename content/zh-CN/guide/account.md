## 什么时候需要账号

本地功能（战役、作品、录像、下载 GitHub 内容）不需要账号。账号只在用到官方在线服务时需要：创意工坊下载、创作者中心、每周突变在线校准、经验与签到。

侧栏底部的头像就是入口，显示当前昵称，未登录时显示「未登录」。这个入口只在「设置 → 功能管理 → 星际枢纽官方服务」开启时出现；关闭官方服务后，账号页只显示「星际枢纽官方服务已关闭，可在设置中重新开启。本地功能仍可使用。」

## 登录、注册与找回密码

未登录时页面有三个模式：登录、注册、忘记密码。

| 场景 | 需要填写 |
| --- | --- |
| 登录 | 邮箱、密码 |
| 注册 | 邮箱、密码、设备名称、六位验证码、邀请码（是否必填由服务端注册策略决定） |
| 忘记密码 | 邮箱、新密码、设备名称、六位验证码 |

几个实际规则：

- 邮箱 3–254 字符，必须包含 `@` 与域名点。
- 登录密码 1–128 字符；注册与重置要求 8–128 字符，且同时包含大写字母、小写字母、数字和 ASCII 特殊符号。
- 「申请验证码」有至少 60 秒冷却，冷却期间按钮显示剩余秒数。验证码申请受理不代表邮件已投递，没收到就等冷却结束再申请一次。
- 验证码为六位数字，界面会显示剩余有效时间。

登录成功后提示「已登录」；重置密码成功会提示「密码已重置，请重新登录。」并回到登录模式。

账号开启了[两步验证](#两步验证)时，登录后还要再做一次验证：选择「验证器六位代码」或「恢复码」，通过后才真正登录，验证窗口的有效期为 300 秒。

## 账号资料

- **昵称**：可修改，8–16 个字符，不能包含空格、Emoji 或连字符。成功提示「昵称已更新」。
- **邮箱**：仅展示，当前版本不提供修改入口。
- **用户 ID**：点「查看ID」后可复制，反馈问题时附上它能加快定位。

## 经验与等级

个人中心显示当前等级、累计经验与进度条。等级门槛是累计经验 100 / 600 / 2000，对应 LV0 到 LV3，LV3 为当前最高等级，满级后经验仍会继续累积。

**每日签到**：说明写的是「每天北京时间 00:00 重置，首次签到奖励 10 经验。」点「立即签到」即可，当天已签到按钮会变成「今日已签到」并禁用。签到后提示「签到成功」与本次获得的经验。

经验信息读取失败时显示「经验信息暂不可用，请刷新重试。」，此时签到也会一并不可用。

## 两步验证

「账号资料」卡片里的「账号安全」分组管理两步验证，状态显示为「已启用双重验证」或「未启用双重验证」，并显示剩余恢复码数量。

### 启用

点「启用两步验证」，弹窗给出发给验证器的绑定二维码与 Base32 密钥，用验证器扫码或手动输入后，填写六位动态码，点「确认并启用」。

启用要求**最近五分钟内登录过**，超时会提示「启用两步验证需要最近五分钟内登录，请退出后重新登录再试。」

启用成功后进入恢复码页：恢复码**只显示这一次**，每个只能用一次，勾选「我已安全保存恢复码」后才能点「完成」。请把它们存到密码管理器之类的地方，这是验证器丢失后唯一的退路。

### 日常维护

已启用后还有四个操作，都需要先通过一次近期验证（动态码或恢复码，有效期最多 5 分钟）：

| 操作 | 影响 |
| --- | --- |
| 验证当前会话 | 只是让本次会话进入已验证状态，不改动任何凭据 |
| 重新生成恢复码 | 旧恢复码全部立即失效，并撤销其他登录会话；验证器不变 |
| 更换验证器 | 重新绑定；确认前旧验证器仍有效，确认后旧验证器、旧恢复码与其他会话全部失效 |
| 停用两步验证 | 账号失去第二因子保护，所有会话与恢复码失效，并需要重新登录 |

恢复码用尽时会警示「恢复码已用尽，建议验证后立即生成。」——此时若验证器也丢了，账号将无法找回，建议尽早补齐。

## 退出登录

页面底部的「退出登录」会清除本地凭据。若远端会话撤销失败，会提示「已在本地退出」并说明远端撤销未确认；这种情况下设备上已经没有凭据，但服务端会话可能仍然存在，可以在其他设备上修改密码来兜底。

关闭「星际枢纽官方服务」时也会清除本地登录状态，重新开启后需要再次登录。
