## 它是什么

「星际枢纽」可以启动一个**只监听本机回环地址**的 MCP 服务，让你的 AI 客户端（支持 MCP 的桌面工具）查询本地战役、作品、下载任务与每周突变数据，并在你确认后激活或卸载战役。

服务默认关闭，也不会随应用自动启动，每次都要手动开启。它与账号、官方在线服务无关，不需要登录。

## 开启服务

1. 打开「设置 → 功能管理」，把「智能助手」开关打开，侧栏才会出现「智能助手」。
2. 进入「智能助手 → 服务配置」，确认端口（默认 `17861`，可用范围 1024–65535）。
3. 点「启动服务」，状态徽章变为「运行中」。

停止有三种方式：点「停止服务」、关闭功能管理里的开关、退出应用。

端口被占用时提示「端口已被占用，请更换端口后重试。」，换一个端口再启动即可。

## 连接客户端

服务地址是 `http://127.0.0.1:<端口>/mcp`，需要携带令牌访问：

1. 点「显示令牌」查看，或直接「复制令牌」。
2. 点「复制连接配置」，得到一段可直接粘进客户端配置的 JSON：

```json
{
  "mcpServers": {
    "scnexus": {
      "type": "http",
      "url": "http://127.0.0.1:17861/mcp",
      "headers": { "Authorization": "Bearer <令牌>" }
    }
  }
}
```

令牌在每次启动应用时重新生成，只存在内存里。重启应用或点「重新生成令牌」后，旧配置立即失效，需要重新复制。重新生成会断开所有已连接的客户端。

## 提供的工具

| 工具 | 用途 | 权限 |
| --- | --- | --- |
| 获取应用状态 | 查看应用与游戏配置状态 | 只读 |
| 查询战役列表 | 浏览已安装战役 | 只读 |
| 查看战役详情 | 按本地标识查看单个战役 | 只读 |
| 查询自制作品 | 浏览已安装的地图与模组 | 只读 |
| 查询下载列表 | 查看可见的下载任务摘要 | 只读 |
| 获取任务状态 | 查询单个任务的进度 | 只读 |
| 查询突变因子 | 搜索并分页查看突变因子 | 只读 |
| 查询每周突变 | 查看指定地区的本周突变 | 只读 |
| 激活战役 | 无冲突时直接激活已安装战役 | 修改游戏文件 |
| 切换战役 | 先还原当前战役，再激活目标战役 | 修改游戏文件 |
| 还原战役 | 停用战役并还原原始文件 | 修改游戏文件 |
| 卸载战役 | 卸载已安装战役 | 修改游戏文件 |

修改类工具默认每次都要在弹窗里确认。战役激活、切换、还原、卸载四张卡片上可以打开「始终自动批准」，打开时会先弹一次风险确认；即使开启，**文件冲突仍要回到应用界面手动处理**，自动批准只跳过工具级确认，不会跨工具生效。

## 操作记录

「操作记录」页只保留最近 500 条，且仅在内存中：记录工具名、状态（执行中 / 成功 / 失败 / 已取消）、开始时间与耗时，**不记录请求参数**，应用重启即清空。需要长期日志请到「设置 → 日志与隐私 → 日志目录」。

## 安全边界

服务在设计上限制得比较死，了解这些能省去排查时间：

- 只监听 `127.0.0.1`，不接受外部地址访问。
- 每次请求都校验 `Authorization: Bearer <令牌>`，令牌错误直接 401。
- `Host` 必须严格是本机地址，请求带 `Origin` 头会被拒绝（403）——浏览器页面无法调用，只有能自定义请求头的本机客户端才行。
- 只接受 `POST /mcp`、`Content-Type: application/json`，请求体上限 64 KiB，并发上限 16。
- 不提供任意命令执行、任意文件读写或启动下载的能力。
