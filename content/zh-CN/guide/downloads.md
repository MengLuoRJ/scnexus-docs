## 两种来源

「下载管理」是内容进入本地的统一入口，支持两类来源：

| 来源 | 要求 | 取回的内容 |
| --- | --- | --- |
| GitHub 仓库 | 公开仓库，根目录有符合标准的 `package.json` | 该分支最新提交的压缩包 |
| 星际枢纽创意工坊 | 登录并开启创意工坊 | 作品当前已审核的发布版本 |

GitHub 来源不需要登录，也不需要开启官方服务；工坊来源两者都需要。仓库要满足的条件——清单放在哪、目录怎么摆、地址与分支怎么写——见 [GitHub 安装源标准](/reference/github-source)。

页面顶部写明流程：「下载完成后，点击"安装"继续。安装前可以查看文件并确认是否覆盖已有内容。」下载与安装刻意分开，避免下载完就往游戏目录里写东西。

## 新建任务

点「新建任务」打开窗口，先选来源。

**GitHub 仓库**：填仓库地址（`https://github.com/所有者/仓库`）与分支（默认 `main`）。地址或分支不合法会即时提示。

**星际枢纽创意工坊**：填作品编号（`SCNID`，1–2147483647 的整数）。未登录时会先跳到个人中心登录，回来后自动重开窗口。

点「获取信息」后，应用先探测来源再显示预览：

- 工坊：标题、简介、`SCNID` 与版本号。
- GitHub：清单里的名称、简介、作者、版本、类型（战役 / 自制 / 依赖）、所属战役、`SCNID`、许可证、主页，以及仓库与提交号。

确认无误后点「确认下载」，提示「下载任务已创建」。取不到信息时会给出具体原因，例如「该作品暂无已审核发布版本」，或仓库不公开、分支不存在、清单不符合标准。

## 任务列表

任务分「进行中」和「历史记录」两个标签页：已完成、已取消、失败归入历史，其余在进行中。

每条任务显示名称、状态徽标、进度条、`已传输 / 总大小 · 速率`、来源行与创建 / 完成时间。来源行对工坊任务显示作品编号，对 GitHub 任务显示仓库与提交号。

状态取值：已暂停、传输中、已完成、失败、结果不明、已取消。

可用的操作按状态变化：

| 操作 | 何时出现 | 行为 |
| --- | --- | --- |
| 暂停 | 传输中 | 停止写入但保留已完成的分片 |
| 恢复 | 已暂停 / 失败 | 从断点继续，不重新下载 |
| 取消 | 未完成、未取消 | 中止并删除临时文件 |
| 删除任务 | 非传输中 | 询问删除范围 |
| 安装 | 已完成 | 校验后进入安装流程 |

传输按 16 MiB 分片进行，支持断点续传：暂停保留临时文件，取消才会删除，所以想接着下就选暂停。

「删除任务」会先检查缓存文件是否还在：文件存在时可选「仅删除记录」或「记录和文件」，文件已不存在则只能删记录。

右上角「打开下载位置」直接打开当前下载目录。**下载目录在创建任务时就已绑定**，之后在设置里改目录不影响已有任务。

## 安装

点「安装」后依次进行：

1. 校验缓存文件的 SHA-256 与大小；
2. 分析包内容，识别是战役、自制作品还是依赖包；
3. 打开安装窗口，选择安装模式、启动器地图（自制作品）和文件冲突处理（覆盖 / 保留，也可批量选择）；
4. 点「确认执行」写入游戏。

安装完成提示「安装完成」；失败时提示检查游戏设置或重新分析文件。战役装完后仍需[激活](/guide/campaign)才会覆盖游戏战役。

安装过的依赖包会在列表下方单独列出，显示名称与版本，可查看详情或卸载。卸载依赖时，共享或已修改的资源需要逐个选择「保留本地文件」或「删除共享文件」，不会静默删除其他作品的文件。

## 出错时

传输层报错时会提示「暂时无法完成传输，请检查网络后重试。上传状态不明时，请勿重复提交。」——这里说的是上传任务；下载任务失败直接点「恢复」续传即可，反复新建任务只会产生重复文件。
