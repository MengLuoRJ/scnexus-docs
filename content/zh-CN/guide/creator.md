## 获得创作者资格

创作者中心需要三层前提：官方服务与创意工坊开关都已开启、账号已登录、账号具备创作者资格。不具备资格时，侧栏不会出现创作者中心与上传管理的入口；即使手动进入，也会被带回个人中心，且不会给出提示。

资格在「个人中心」的「创作者资格」卡片里查看，状态包括未激活、已激活、已撤销、已封禁、尚未获取。未激活时可用邀请码开通：点「使用邀请码激活」，输入 8–64 位字母、数字、下划线或连字符组成的一次性邀请码即可。

资格生效后，侧栏才会出现「创作者中心」与「上传管理」两个入口。

## 创作者中心

页面顶部是作品切换条，用来切换当前编辑的作品。作品数量受**创作者额度**限制：默认 5 个，额度由管理员按创作者单独分配，需要更多可以申请调整。达到上限时「创建作品」不可点。选中作品后进入编辑区。

### 维护作品资料

表单字段与长度限制：

| 字段 | 限制 |
| --- | --- |
| 作品名称 | 必填，≤120 字 |
| 作品网站 | ≤2048 字 |
| 作品简介 | ≤1000 字 |
| 社交与赞助 | 固定键（Twitter、Discord、YouTube、微博、Bilibili、QQ 群、PayPal、Patreon、Buy Me a Coffee、爱发电），每项 ≤2048 字 |

「详细介绍」是富文本编辑器，可以插入图片：点「上传图片」选择 `png` / `jpg` / `webp`，单件作品最多引用 50 张，被正文引用的图片不能直接「移除引用」。

点「保存草稿」写入服务端。注意页面上的提示：**保存只修改草稿，公开内容仍需审核**。多人同时编辑同一作品时，若服务端资料已被更新，会出现「作品信息已更新」的冲突提示，此时需要先保存自己的文字，再点「放弃编辑并重新加载」取回最新版本。

已有作品会显示一行概要：`SCNID · 资料版本 · 状态`。

### 提交新版本

版本区在作品下方：

1. 点「选择并验证压缩包」，选择 `zip` / `7z` / `rar`。应用会按你账号的额度核对体积（默认单个版本包 ≤ 300 MB），再检查路径安全与清单，通过后显示文件名、字节数、清单里的版本号与 `SHA-256`，可展开「包清单」核对字段。
2. 需要的话点「从安装包填写资料」，用清单里的名称、简介、网站、社交与赞助预填表单，提示「资料已预填，请确认后保存」。
3. 填写「更新日志」。日志里引用的图片必须已经存在于作品图片列表中，否则会提示先保存作品图片。
4. 点「创建版本并上传」。

版本号必须是严格语义化版本（如 `1.2.3`）；如果清单里声明了作品编号，必须与当前作品的 `SCNID` 一致，否则界面提示「请使用类似 1.2.3 的版本号，并确认压缩包中的作品编号与当前作品一致。」

**同一作品同时只能有一个候选版本**。已有版本在处理中时，页面会提示「已有一个版本正在处理，请完成或取消后再提交新版本。」候选版本状态为草稿或待审核时，可以点「取消待发布版本」撤销；如果它仍在上传，请先到上传管理取消上传任务。

## 上传管理

「上传管理」列出全部上传任务（含作品图片上传），每条显示名称、状态、进度、已传输字节与 `File ID`，失败时直接展示错误原文。

操作按状态出现：

| 状态 | 可用操作 |
| --- | --- |
| 传输中 | 暂停、取消 |
| 已暂停 / 失败 | 恢复、取消 |
| 已完成 / 已取消 | 无 |

若状态是「结果不明」，页面会提示「无法确认上传是否完成。请取消此任务后重新上传，避免重复提交。」——这种情况**先取消再重传**，不要直接重新提交，否则可能产生重复上传。

上传完成后，版本仍需通过审核才会公开；审核进度在创作者中心的版本记录里查看。
