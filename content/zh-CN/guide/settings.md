## 基本设置

| 项目 | 说明 |
| --- | --- |
| 界面语言 | 跟随系统 / 简体中文 / English / 繁體中文。保存后立即生效，不需要重启；跟随系统时无法识别语言会回退简体中文 |
| 下载目录 | 下载任务的保存位置，默认是系统下载文件夹。「修改目录」选择新路径，「打开目录」直接打开。**已有任务仍写在创建时的目录里**，改设置只影响之后新建的任务 |
| 版本与更新 | 显示当前版本与更新状态，按钮依次为「检查更新」→「下载更新」→「退出并安装」。仅打包版 Windows 支持，开发模式或非 Windows 会显示「当前环境不支持自更新」 |
| 帮助与服务 | 官网指南、用户协议、隐私政策、交流社群、赞助支持五个外链，均用系统浏览器打开 |

更新不会在启动时自动检查，也不会自动安装，需要手动点一次「检查更新」。发现新版本后先「下载更新」，下载完成按钮才变成「退出并安装」。

## 游戏环境

这一页决定应用能不能读写游戏数据，卡片右上角的徽标显示「已就绪」或「未配置或不可用」。

| 项目 | 说明 |
| --- | --- |
| 游戏根目录 | 「选择目录」手动指定，「重新检测」重新扫描安装位置。未就绪时战役、作品的安装与激活都会被拒绝 |
| 内容管理目录 | 由游戏配置推导，仅供查看与打开 |
| CCM 管理目录 | 同上 |
| 星际 II 文档目录 | 存放 `Accounts` 与录像的目录。留空时使用系统「文档 / StarCraft II」；自定义时会校验路径必须是目录，并标注当前正在使用自定义目录还是系统目录 |
| 识别星际资料 | 读取该目录下的资料列表，显示简称与账号 ID。找不到时提示确认目录正确并已在游戏中创建资料 |
| 使用默认目录 | 清空自定义路径，回到系统默认位置 |

录像管理、作品与战役的「星际资料」选项都依赖这里，目录配错会表现为「未识别到星际资料」。

## 功能管理

四个开关，决定侧栏出现哪些入口：

| 开关 | 默认 | 打开后的效果 |
| --- | --- | --- |
| 智能助手 | 关闭 | 侧栏出现「智能助手」，可启动本地 MCP 服务；关闭时立即停止服务 |
| 星际枢纽官方服务 | 开启 | 启用账号、每周突变在线校准与创意工坊 |
| 创意工坊 | 开启 | 启用工坊、创作者中心与工坊传输；父开关关闭时此项不可改 |
| 每周突变在线校准 | 开启 | 用官方服务校准每周突变结果；关闭后仍按本地数据与规则显示 |

关闭「星际枢纽官方服务」会**清除本地登录状态**，侧栏账号入口隐藏、工坊相关页面跳到设置页；本地功能与 GitHub 下载不受影响。重新开启后需要再次登录。

关闭「创意工坊」只暂停进行中的工坊任务并保留任务与文件，**重新开启后不会自动恢复**，需要到下载管理里手动恢复。

## 日志与隐私

| 项目 | 说明 |
| --- | --- |
| 日志目录 | 运行日志位置，「打开目录」直接跳转。反馈问题时请附上这里的日志 |
| 日志输出等级 | `error` / `warn` / `info` / `verbose` / `debug` / `silly`，默认 `error`。等级越高记录越详细，也越占空间 |
| 在线分析 | 静默统计访问与在线状态，离线时暂停、恢复网络后继续。与错误遥测相互独立 |
| 错误遥测 | 授权后发送脱敏错误与堆栈，用安装标识关联，不含截图、内存转储或账号身份。默认关闭 |

错误遥测开启后，下方会显示运行状态：初始化失败通常意味着当前环境不支持或未配置上报端点，可尝试重启应用。已发出的报告无法撤回，关闭只影响之后的数据。

在线分析不需要授权确认，错误遥测则需要你先打开开关——两者互不影响，可以只开其中一个。
