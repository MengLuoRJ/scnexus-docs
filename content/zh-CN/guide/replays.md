## 使用前提

录像按「星际资料」组织，所以要先在「设置 → 游戏环境」里指定星际 II 文档目录，并用「识别星际资料」读出资料列表。页面顶部没有可选资料时，会提示「未识别到星际资料，请在设置中心配置星际文档目录。」并提供「打开设置」。

## 页面结构

顶部是资料与类型的选择：

| 控件 | 说明 |
| --- | --- |
| 星际资料 | 下拉选择要查看的资料 |
| 录像类型 | 多人游戏 / 战役 / 挑战 |
| 刷新 | 重读当前资料与类型对应的目录 |
| 扫描目录 | 把目录里的录像导入索引 |
| 导入 | 「导入录像」单个文件，或「导入压缩包」批量 |
| 多选导出 | 进入勾选模式，打包为 ZIP |

切换资料或类型时会自动刷新索引，但**不会监听文件夹**：在游戏外新增或删除录像后，需要手动「刷新」或「扫描目录」。

导入的录像会被**复制**到该资料对应类型目录，不只是登记一条记录。

## 录像列表

支持按文件名、地图、玩家或路径搜索。每行展示文件名、地图、玩家与种族、游戏时长、对局时间（本地时间）、文件大小和元数据状态。

「元数据状态」有四种：

- **已支持**：完整解析。
- **部分支持**：只解析出部分字段，界面注明「仅显示已解析的元数据；不提供对局分析。」
- **不支持**：当前版本无法解析。
- **已损坏**：文件本身有问题。

点击「详情」查看文件信息（路径、大小、修改时间）、对局时间、地图、版本、基础构建号、玩家种族与队伍、结果、时长。

## 重复录像

索引时按文件内容的 SHA-256 分组，同一份录像的多个副本会被归入同一组。开启「只看重复录像」即可只看这些分组，切回「查看全部」恢复完整列表。

去重只是**标记与分组**，不会自动合并或删除文件；手动改过文件后需要重新索引，分组才会更新。

## 对局数据

选中一条录像点「分析」（已分析过的显示「重新分析」），生成的「对局分析」包含：

- 资源储量曲线（晶体矿、高能瓦斯）。
- 资源收入 / 分钟。
- 工人及人口快照。
- 生产时间线：实体出现、生产开始、生产完成、升级完成。

横轴是游戏时间（每秒 16 个游戏循环），不是现实时间；曲线只连接实际采样点，缺失区间留空，不做平滑或推算。长录像为保持流畅最多显示 1000 个采样点。

需要说明的是，这里的「完成」只表示协议组件解码成功，**它不是 APM、建造顺序或经济分析**；当录像缺少采样数据或事件无法识别时，界面会明确提示数据可能不完整。

## 批量导出

点「多选导出」进入勾选模式，可以逐条勾选，或用「选择可见项」把当前筛选结果全部加入，顶部显示「已选：N」，随时可以「清空」。

确认后选择一个新的 ZIP 路径导出，不会覆盖已有文件。单次上限为 **2000 个录像 / 1 GiB**，导出完成会提示数量与保存位置。筛选条件变化不会清空已勾选项。

## 删除

「删除」是**永久删除**：磁盘上的录像文件与索引记录一起移除，无法撤销。弹窗会明确写出这一点，需要再点一次「永久删除」确认。
